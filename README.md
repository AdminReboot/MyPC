# MyPC

Công cụ tiện ích cho máy tính Windows.

| Thư mục | Mô tả |
|---|---|
| [`netwatchdog/`](netwatchdog/README.md) | **NetWatchdog**: theo dõi mạng, tự đổi Wi-Fi / khởi động lại card mạng / khởi động lại máy khi rớt mạng, mở lại ứng dụng đã chọn và báo cáo tình hình máy lên Telegram. Có thêm tùy chọn theo dõi nhân vật jxtdAuto. |

**Tải về:** bộ cài Windows mới nhất ở trang [Releases](https://github.com/AdminReboot/MyPC/releases/latest).
